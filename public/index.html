开始使用阅伴

打开文件即可先阅读。本地全文准备与在线提交分开，提交卡顿不影响打开、翻页或缩放。提问只等待必要的本地准备，无需等待后台提交结束。

  1. 整份文档：后台提取全文并缓存；提问复用课程上下文，通常只需传递问题与页码。
  2. 当前页 / 选中文字：在输入框的“选项”中调整讲解重点，仍保留全文上下文，可联系前后章节。
  3. PPTX：保留原比例与排版，第一页显示后，后台持续渲染其余页面并提取全文。

扫描页在本机后台识别并缓存；默认不附图，图表等内容按需查看原图。“＋ 图片”可选择或粘贴补图，选项中也可开启“总是附当前页图片”。提问自动编号，可用“问题定位”“查看回答”与“回到主问题”跳转；点击“追问这段”引用原讲解。

HTML / HTM 支持单文件课程，保留网页排版和常见脚本交互，使用连续阅读；上方编号表示正文段号，可用于定位。支持全文问答、选中文字和独立缩放。依赖旁边资源文件夹的页面可能缺图或缺样式；网页图表需手动补截图。HTML 内嵌笔记暂不跨次保存，阅读器聊天仍正常保存。

阅读区顶部可切换“连续阅读 / 单页阅读”。连续模式中滚轮上下滑动；单页模式中，页面内的滚轮逐页翻阅，页面外的滚轮只上下滑动。切换模式保留当前页；第一页显示后，后台继续准备其他页。

Ctrl + 鼠标滚轮按鼠标位置独立缩放：左侧调整文档，右侧调整问答文字，不改变整个窗口。左侧“适合宽度”重置文档缩放，右侧出现的百分比按钮恢复文字到 100%。顶部可收起问答栏，草稿和记录会保留。

输入框的“选项”可调整提问范围、附图、模型和回答速度。设置对下一条回答生效。课程知识结构优先用层级提纲、对比表和公式直接呈现。

右上角“菜单”包含打开文档、快速重启、新建对话、导出和连接操作；点击页数状态可查看全文准备详情。快速重启保留文档、页码、草稿与记录，正在生成的回答会停止，未完成的问题需要重新发送。

阅读器使用临时 Codex 会话，普通提问、课程准备和自动任务均不写入 Codex 持久历史。问答与课程文字保存在阅读器本机目录；重新打开同一文件后恢复记录，重启后按需要恢复课程全文和最近对话上下文。

临时会话仍会联网发送问题和所需文档内容以获得回答。这项设置控制 Codex 历史列表，不代表离线处理或服务端零留存。升级时仅归档旧版阅读器在自己临时目录中创建的会话，保留本地问答。

打开文件后会自动在线提交全文文字，使用当前 Codex 账号权限与额度。不会先把全部图片逐批交给模型分析；需要图表时自动获取对应页。接收完成也不代表复杂题目已经算出答案；提问仍需模型思考。
