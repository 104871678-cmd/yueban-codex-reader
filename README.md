# 阅伴 · Codex Reader

Windows 本地 PDF / PowerPoint 阅读器，在阅读界面旁使用自己的 Codex 登录进行课程问答。

## 下载与启动

在本仓库的 **Releases** 中下载 ZIP，解压后双击 **启动阅伴.cmd**。请保持整个程序文件夹完整。

需要以下环境：

- Windows，Node.js 22 或以上版本。
- 可运行 app-server 的 Codex 程序，并已登录自己的账号。启动时自动查找常见安装位置与系统路径；特殊路径可用 CODEX_READER_CODEX 指定。
- 阅读 PPTX 原版需要本机 WPS 或 Microsoft PowerPoint；旧 PPT 建议先另存为 PPTX / PDF。仅阅读 PDF 不需要安装办公软件。
- 扫描页文字识别使用 Windows 本机 OCR 和已安装语言；不可用时可按需查看页面原图。

启动器自动查找 Node.js；特殊路径可用 CODEX_READER_NODE 指定。当前版本不会自动安装缺少的软件或代替用户登录。

## 功能

- PDF 可选择文字，支持连续阅读和单页阅读、页码跳转。
- PPTX 保留原始比例和排版，第一页显示后持续在后台渲染后续页面。
- 本地阅读与在线准备分开，提交卡顿不影响打开、翻页和缩放。
- 全文提取、扫描页识别与缓存在本机后台运行；普通问答复用全文上下文并携带当前页码，图表和复杂公式按需获取原图。
- 支持补充图片、粘贴截图、问题编号、引用追问与双向跳转。
- 可收起问答区、使用深色背景；Ctrl + 滚轮分别缩放阅读区和回答文字。
- 可调整回答速度，导出对话和解答；直接输入“解答全部习题”可启动分批任务。

本机全文或扫描识别尚未完成时，提问可能需要等待，本地阅读仍可继续。首次建立模型上下文与回答仍受文档长度、模型和网络影响。

## 数据与账号

使用每位用户自己的 Codex 登录与账号额度。在线问答会将必要的文档内容发给模型；程序采用全文提取与按需页面读取，没有把 PDF / PPT 原生附件直接上传的接口。

阅读器使用临时 Codex 会话，不写入 Codex 持久历史列表；这不等于服务端零留存。完整聊天、课程缓存和 OCR 结果保存在本机 data/ 中。公开源码与下载包不包含作者的登录凭据、个人课程缓存或聊天记录。

## 说明与开发

完整使用说明见 [使用说明.md](使用说明.md)。示例 PDF 与习题解答随程序提供。

程序使用 Node.js 内置模块、浏览器界面，以及本机 Windows / 办公软件能力。直接运行 node server.mjs 可启动服务；也可执行 node --test test/*.test.mjs 运行模拟模型测试。

第三方组件及许可证见使用说明末尾和 public/vendor/ 内的许可证文件。项目为独立工具，与 OpenAI、WPS、Microsoft 无隶属关系。
